A responsive-ready hero section for a fictional web agency, "Mrex's Devs & Designers". It is a static landing page built with HTML and CSS to practice layout, typography and background images.

## Features

- Full-screen background image with `background-size: cover` and a fixed attachment
- Bold headline and tagline with a custom underlined highlight (`text-decoration` with `text-underline-offset`)
- Call-to-action button with hover and active (press) states
- Google Fonts (Open Sans)

## Tech Stack

- HTML5
- CSS3

## Getting Started

No build step is needed.

1. Clone the repository:

```bash
   git clone https://github.com/jooant/Web_Agency_Hero.git
   cd Web_Agency_Hero
```

2. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Project Structure

```text
├── index.html        # Page markup
├── styles.css        # Styles
├── img/
│   └── mrex-office.png   # Background image
└── README.md
```
